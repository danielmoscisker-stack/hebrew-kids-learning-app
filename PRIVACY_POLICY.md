# Privacy Policy — אותיות ומספרים לגיל 4 (Kids Hebrew & Numbers)

**Last updated:** November 2026

## 1. Zero Data Collection (100% Kid-Safe & Offline)
**אותיות ומספרים לגיל 4** (`com.learningapp.hebrewkids`) is an educational app designed for 4-year-old children.

We **do not** collect, store, transmit, share, or sell any personal information or usage data:
- **No accounts or logins**
- **No analytics, telemetry, or tracking SDKs**
- **No advertisements or third-party ad networks**
- **No in-app purchases**
- **No external audio/font network calls** — all voice recordings and fonts are bundled inside the app.

## 2. Local Device Storage Only
The app uses on-device local storage (`localStorage`) solely to remember:
- Star/sticker reward progress
- Boy / girl voice conjugation preference
- Desktop cursor preference

This data never leaves the device and can be cleared at any time by uninstalling the app or using **Reset Stars** inside the Parent Gate.

## 3. Parental Gate
Settings, language switching, and external pedagogy notes are placed behind an arithmetic **Parental Gate** in accordance with Google Play's **Designed for Families** and Apple's **Kids Category** guidelines.

## 4. Contact
If you have any questions about this privacy policy, please open an issue on our GitHub repository or contact the developer via the store listing email.
