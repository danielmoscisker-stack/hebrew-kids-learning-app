# אותיות ומספרים לגיל 4 | Kids Hebrew & Numbers Learning App

אפליקציה חינוכית ואינטראקטיבית לילדים בני 4, שנבנתה ישירות מתוך חוברת 15 הדפים של כרטיסיות האלף-בית, ומותאמת במלואה לתכנית הלימודים של **משרד החינוך בישראל (תשתית לקראת קריאה וכתיבה בגיל הרך)** עם תוספת עולם המספרים 1 עד 10.

האפליקציה פועלת בדפדפן מחשב, טלפונים ניידים וטאבלטים (PWA), ומוכנה לחלוטין לאריזה כ-APK והעלאה לחנות האפליקציות של גוגל (Google Play Store).

## 🧠 עקרונות פסיכולוגיה ועיצוב משחקים לילדים בני 4

1. **עוגנים סומאטיים ופיזיים (שיטת הפופיק והבעות הפנים):**
   - בגיל 4 מושג ה"דגש" או ה"ניקוד" מופשט מדי. הקישור לנקודת ה"פופיק בבטן" יוצר עוגן גופני מוחשי שקל להבין.
   - עולם הניקוד מוצג דרך הבעות פנים טבעיות שילד עושה ביומיום: "פה פתוח כמו אצל רופא (אָההה)", "חיוך שמראה שיניים (אִי-אִי)", "פה עגול ומופתע (אוֹוֹו)", "שפתיים ששורקות (אוּ-אוּ)".

2. **משוב חיובי מתמיד (Zero-Penalty & Errorless Learning):**
   - אין "פסילות" או צלילי שגיאה חדים. כאשר הילד נוגע באות בלי פופיק, האפליקציה מחזקת בחיוך: "רוּחַ... בֶּטֶן רֵיקָה, בּוֹא נְחַפֵּשׂ שׁוּב!".
   - קונפטי, צלילי פעמונים ומד כוכבים מעודדים תחושת מסוגלות והצלחה (Self-Efficacy).

3. **מטרות מגע מותאמות למוטוריקה עדינה של גיל 4:**
   - כל הכפתורים והכרטיסיות הם בגודל מינימלי של 56-80 פיקסלים עם פינות עגולות רכות.
   - לחיצות תלת-ממדיות מוחשיות (`btn-press-3d`) שמספקות תחושת מישוש מיידית.

4. **תמיכה דו-לשונית מלאה (עברית ואנגלית):**
   - כפתור החלפה מהיר בחלק העליון (`עברית 🇮🇱` / `English 🇬🇧`).
   - מקריא הן את המילים בעברית תקנית מנוקדת והן באנגלית, כולל תעתיק פונטי לכל מילה.

## 🚀 הרצה מקומית של האפליקציה

1. התקנת תלויות (אם נדרש):
   ```bash
   npm install
   ```
2. הפעלת שרת פיתוח:
   ```bash
   npm run dev
   ```
   האפליקציה תהיה זמינה בכתובת: `http://localhost:5173`
   
   כדי לפתוח את האפליקציה ממכשירים אחרים באותה רשת ביתית, היכנסו אל `http://<כתובת-IP-מקומית>:5173` (אפשר למצוא את כתובת ה-IP של ה-Wi-Fi באמצעות `ipconfig`). אם Windows Firewall מבקש אישור, אפשרו גישה ברשת פרטית בלבד.

3. בנייה לגרסת ייצור (Production Build):
   ```bash
   npm run build
   ```

## 📱 אריזה כאפליקציית אנדרואיד (Android APK / Google Play Store)

האפליקציה בנויה לפי תקן **PWA** ומותאמת להמרה מיידית לאפליקציית אנדרואיד באמצעות שתי דרכים מומלצות:

### אפשרות א': באמצעות Capacitor (מומלץ ביותר לחנות גוגל פליי)
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Kids Hebrew & Numbers" "com.learningapp.kids" --web-dir dist
npm run build
npx cap add android
npx cap open android
```
זה יפתח את הפרויקט ב-Android Studio, משם ניתן לייצא קובץ `APK` או `AAB` (Android App Bundle) להעלאה לחנות.

### אפשרות ב': באמצעות Bubblewrap (Google TWA)
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest=https://your-domain.com/manifest.json
bubblewrap build
```
